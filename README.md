# Vet Clinic REST API

A REST API for a veterinary clinic built with Spring Boot, PostgreSQL, and JPA. Portfolio project showcasing production-grade Java backend development.

## Tech Stack

- Java 21
- Spring Boot 3.4.1
- Spring Data JPA (Hibernate 6)
- PostgreSQL 16 (Dockerized)
- Lombok
- Maven 3.9

## Features (in progress)

- [ ] Owner CRUD endpoints
- [ ] Pet CRUD endpoints with Owner relationships
- [ ] Veterinarian CRUD endpoints
- [ ] Appointment booking
- [ ] Medical record tracking
- [ ] JWT authentication (Spring Security)
- [ ] Deployed to AWS
